1. GitHub access token (one-time setup)
  1. Go to github.com/settings/personal-access-tokens/new
  2. Set Resource owner to ecommerce1-cloud and Repository access to only UAE-Pricing-Tracker
  3. Under Permissions → Repository permissions, set Contents: Read and write and Actions: Read and write
  4. Generate the token, copy it, and paste it below
